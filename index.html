Browser API Key Transparency & Security Warning

Your Gemini API key is stored locally in this browser's localStorage so this static GitHub Pages app can call Gemini directly without a backend server. localStorage is not encrypted hardware storage—any browser extension or user inspecting browser storage/DevTools can read it. Always configure HTTP referrer restrictions (your GitHub Pages URL) and strict spending/rate quotas in Google AI Studio / Google Cloud Console, and never share a device where your key is saved.

JARVIS AI — Personal Holographic Assistant

100% Static HTML5, CSS3 & Vanilla JavaScript application designed for GitHub Pages and Google Gemini API.

JARVIS AI runs completely inside your browser with zero backend servers, zero PHP, and zero database dependencies. Your conversations, notes, tasks, and preferences are stored strictly in local browser storage on your current device—there is no automatic cloud synchronization across devices.

For security, JARVIS asks confirmation before opening external websites and accurately discloses browser limitations rather than simulating control over operating system hardware or desktop apps.
